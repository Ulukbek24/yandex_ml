# Void Core Station

Void Core Station — боевая космическая станция Iron Dominion. Самое разрушительное оружие в истории галактики, способное уничтожить целую планету одним выстрелом.

## Описание

Void Core Station — сферическая станция диаметром около 160 километров. Внешне напоминает небольшую луну. Внутри размещаются:
- Главный реактор энергии Synth-типа
- Боевая пушка — «Void Cannon» — длиной несколько километров
- Гарнизон в сотни тысяч солдат-Voidguard
- Истребительные ангары с тысячами Shade Wing
- Командный мостик в верхней полусфере

## Принцип работы

Void Cannon концентрирует энергию реактора в единый луч разрушительной силы. Для полной зарядки требуется около суток. После выстрела планета сначала распадается на части, затем эти части полностью дезинтегрируются.

Первым и единственным применением Void Cannon в боевых условиях стало уничтожение Elyndra.

## Уязвимость

Несмотря на колоссальные размеры и защиту, Void Core Station имела критическую уязвимость — небольшое вентиляционное отверстие, ведущее прямо к главному реактору. Попадание туда одного термоядерного заряда запускало цепную реакцию, которую невозможно было остановить.

Эти данные содержались в технических чертежах, похищенных агентами Luminary Front. Именно их передала RX-2, а через него — Mira Aldyn.

## Уничтожение

В ходе Битвы за Xerath Zael Kiran пилотировал Sky Lance и направил торпеду точно в вентиляционное отверстие. Void Core Station взорвалась, уничтожив значительную часть флота Iron Dominion вместе с собой.

Это событие стало переломным в войне Luminary Front против Iron Dominion.

## Вторая версия

Iron Dominion начала строительство второй, ещё более крупной Void Core Station после потери первой. Эта станция была почти завершена к моменту Битвы за Verath и также была уничтожена — на этот раз изнутри, в ходе диверсионной операции.
