# Krath Brotherhood

Krath Brotherhood — тайная организация практиков Void Path Synth Flux. Главные антагонисты Luminari Order на протяжении тысячелетий.

## История

Krath Brotherhood возникло из конфликта внутри раннего Luminari Order. Группа практиков решила, что ограничения Radiant Path мешают раскрыть истинный потенциал Synth Flux. Они выбрали Void Path — более быстрый и мощный, но разрушительный путь.

После изгнания из Ордена они объединились и основали собственную традицию, которую назвали Brotherhood. Главное правило Krath Brotherhood: может быть только два — Мастер и Ученик. Не больше, не меньше.

## Принцип «двоих»

Правило двух существует по двум причинам. Во-первых, оно не позволяет Brotherhood накапливать силу открыто — двое всегда в тени. Во-вторых, оно предотвращает внутренние конфликты, которые уничтожили ранние версии Brotherhood.

Ученик всегда стремится превзойти Мастера — это поощряется. Мастер всегда держит ученика под контролем. Когда ученик становится достаточно силён — он убивает Мастера и берёт собственного ученика.

## Методы

Krath Brotherhood использует страх, манипуляции и силу. В отличие от Luminari, которые предпочитают переговоры, Krath Brotherhood склонны к прямому насилию или психологическому давлению.

Практики Void Path часто используют:
- Void chains — электрические разряды через Synth Flux
- Принуждение — подавление чужой воли
- Ложные обещания — обман, который они сами считают инструментом

## Последние члены

- **Sovereign Vectus** — Мастер
- **Krath Velgor** — Ученик

После гибели обоих Brotherhood формально прекратило существование.
